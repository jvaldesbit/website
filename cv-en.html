AI Architect & Tech Lead

HeyGIA  ·  AI voice agents  ·  Hybrid

Joined at the company's founding. Five weeks later, a restaurant chain in Mexico was taking phone orders handled end to end by our voice agent.

  • Designed the ordering gateway (hexagonal Go + React). It never calls an LLM: the agent talks and decides, the gateway validates and submits to the POS. 17 tools under a SemVer contract, p99 ≤ 50 ms per tool, idempotent submission. Each restaurant is configuration, not code.
  • Technical owner of the voice agent (LiveKit Agents): Claude Haiku with prompt caching and OpenAI fallback, Deepgram and ElevenLabs. Moved it to a hexagonal architecture so providers can be swapped without touching conversation logic.
  • Designed the inbound call flow: SIP carrier → LiveKit → dialer → agent on ECS → POS, with SIP transfer to the store.
  • Responsible AI by design: the caller's phone number travels in a header and never reaches the model; PII is encrypted per tenant (AES-256-GCM); payment is recorded as a declaration, keeping PCI out of scope.
  • Chose STT with data, not demos: blind-graded 1,271 segments from 87 real calls, 71% vs 54% accuracy (WER 18% → 13%). The same test showed noise cancellation raised WER from 15% to 24%.
  • Built an internal arena to choose LLMs against the real script: simulated customer, 25 providers, blind LLM judge, latency and cost. Exposed as an MCP server.
  • AI-assisted development with coding agents (Claude Code, GitHub Spec Kit): a lead agent reviews and integrates while others work in isolated worktrees from specs and ADRs. 2,830 commits in 9 weeks.
  • AWS with Terraform across 3 accounts: ECS Fargate ARM64, API Gateway + Cognito, Lambda, Valkey, MongoDB Atlas, Glue/Athena.
